# Personal Portfolio Website

A modern, responsive portfolio website built with React.js, Tailwind CSS, and Framer Motion.....

## Features

- 🎨 Modern and clean design
- 🌙 Dark mode by default with toggle
- 📱 Fully responsive
- ⚡ Fast and optimized performance
- 🎭 Smooth animations and transitions
- 📊 GitHub and LeetCode stats integration
- 📝 Contact form
- 🔍 SEO optimized

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- React Router
- React Helmet Async
- React Type Animation
- React Toastify
- EmailJS/Formspree (for contact form)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Customization

### Personal Information

1. Update your personal information in the respective components:
   - `Home.jsx`: Update name, tagline, and description
   - `About.jsx`: Update education, roles, and achievements
   - `Experience.jsx`: Update work experience
   - `Projects.jsx`: Add your projects
   - `Research.jsx`: Add publications and certificates
   - `Contact.jsx`: Update contact information and social links

2. Update meta tags in `index.html`:
   - Title
   - Description
   - Keywords
   - Open Graph tags
   - Author information

### Styling

1. Colors: Update the color scheme in `tailwind.config.js`
2. Fonts: Change the font family in `tailwind.config.js` and update the Google Fonts link in `index.html`
3. Components: Modify the components in the `src/components` directory to match your preferences

### Contact Form

1. Set up EmailJS or Formspree:
   - For EmailJS: Add your service ID, template ID, and user ID in `Contact.jsx`
   - For Formspree: Replace the form action URL in `Contact.jsx`

### GitHub and LeetCode Stats

1. Update the GitHub username in the GitHub stats components
2. Update the LeetCode username in the LeetCode stats component
